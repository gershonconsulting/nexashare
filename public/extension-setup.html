First installation

  1. Choose one option above. If downloading, extract the ZIP into a permanent folder first.
  2. Open chrome://extensions in Chrome and turn on Developer mode.
  3. Choose Load unpacked and select the downloaded/extracted folder or the local folder path shown above.
  4. Return to the NexaShare dashboard and reload the page.
  5. NexaShare connects the current extension automatically while you are signed in.

Updating an existing installation

  1. If you use the download option, replace the existing extension files with the extracted v1.2.7 files.
  2. If you use the local option, keep the same local folder selected in Chrome.
  3. Open chrome://extensions and choose Reload on NexaShare.
  4. Reload the NexaShare dashboard. The red warning disappears only when Chrome confirms version 1.2.7.
Before the first sync: Chrome must be signed in to LinkedIn. NexaShare opens the required company and post pages automatically. It records success only after LinkedIn visibly confirms the repost.
