Install or update the private Chrome extension

NexaShare cannot install a private extension automatically. Follow these Chrome steps once.

Download extension 1.2.4 ZIP

First installation

  1. Extract the downloaded ZIP into a permanent folder.
  2. Open Chrome Extensions by entering chrome://extensions in Chrome’s address bar.
  3. Turn on Developer mode.
  4. Choose Load unpacked and select the extracted folder.
  5. Return to the NexaShare dashboard and reload the page.
  6. When the dashboard confirms version 1.2.4, choose Connect browser.

Updating an existing installation

  1. Download and extract the newest ZIP into the same extension folder, replacing the old files.
  2. Open Chrome Extensions and choose Reload on NexaShare.
  3. Reload the NexaShare dashboard and confirm it shows version 1.2.4.
Before the first sync: keep a signed-in LinkedIn tab open. NexaShare records success only after LinkedIn visibly confirms the repost.
